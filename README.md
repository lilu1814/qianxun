# 神隠し · 千と千尋の神隠し 3D

『千と千尋の神隠し』を題材にした、非商業の同人 3D インタラクティブストーリー。

第一章「トンネル」、第二章「契約」を収録。Three.js によるローポリの 3D シーン、三人称視点、日中点景から夜への遷移、湯屋の長橋、ボイラー室、湯婆婆の部屋、契約の名場面をプレイできます。

> 非公式のファンメイド作品です。原作・映像・キャラクターの権利は各有権者に帰属します。
> **开发进度：目前已完成第一章「隧道」与第二章「契约」。后续章节敬请期待。**

## 起動

```bash
pnpm install
pnpm dev
```

Open http://127.0.0.1:4173/

Build:

```bash
pnpm build
pnpm preview
```

## 操作

- `A / D`：旋回
- `W / S`：前進 / 後退
- マウス：視点（画面クリックで固定、`Esc` で解除）
- `Shift`：速く歩く
- `Space` / `Enter`：会話を進める
- `E`：調べる / 長橋で息を止める
- ホイール：ズーム

## テキスト設定

`public/config/text.json` で、対話・ナレーション・UI テキストの日本語／中国語を実行時に上書きできます。

- `mode`: `both` / `ja` / `zh`
- `dialogue`: 対話・ナレーション
- `ui`: メニュー、HUD、目標、手記、章カード、エンディングなど

詳しくは `public/config/README.md` を参照してください。

- `public/models/chihiro_work.glb`：千尋の湯屋仕事服モデル（28 ボーン、74 フレームの `Walk` 付き）
- `public/models/yubaba.glb`：湯婆婆モデル（28 ボーン、腕振り `Walk` 1 秒付き）

- `blender/export_haku.py`：白龍 FBX → GLB 変換スクリプト
- `blender/export_chihiro_work.py`：千尋・仕事服 FBX → GLB 変換スクリプト
- `blender/export_yubaba.py`：湯婆婆 FBX → GLB + 腕振りアニメーション

- `blender/export_kamaji.py`：釜爺 GLB のリグ・多腕アニメ・減面・圧縮
- `public/config/text.json`：日中各テキスト設定

## Note

- 対話音声は現在無効です（BGM のみ）。
- 仕事服は `?outfit=work` でプレビューできます（通常は日常服）。
- `blender/source/` の大容量元モデルと元 FBX はリポジトリに含めていません。実行用モデルは `public/models/` にあります。
- 白龍の FBX は 121 フレームのターン／ステップ動作を元に、Blender で身体の向きを打ち消した `HakuWalk` と、元の 180 度ターン `HakuTurn` の 2 クリップへ変換しています。長橋では `HakuWalk` を移動と同期し、橋の終わりで `HakuTurn` により千尋へ向き直ります。

湯婆婆は契約シーンで机の前を左右に往復し、`Walk` の腕振りを再生します。

- 会話・ナレーション中：マウスドラッグで周囲を見回せます。ダイアログ欄をクリックすると次へ進みます。

## 湯婆婆の部屋への入室

ボイラー室の出口扉に近づいて `E` で開け、オフィスへ移動します。オフィスでは自由に机の前まで歩き、もう一度 `E` で湯婆婆との会話を開始します。

- 全シーン共通：マウスでカメラ／進行方向を操作し、`W` でカメラ前方へ前進します。

- `public/images/boh_normal.png`：坊の通常カットアウト（湯婆婆の部屋のテント内）

- 第一章開始から草原を抜けるまでの BGM：`public/audio/that_summer.mp3`（160kbps MP3、189.8秒）。
- 第一章の旧市集から橋・章末までの BGM：`public/audio/nobody_diner.mp3`（160kbps MP3、195.7秒、ループ）。

- 第一章の終盤：市場を抜けて石段を上り、湯屋へ続く橋の場面へ。第二章はボイラー室から開始。

- 第二章ボイラー室の BGM：`public/audio/boiler_bug.mp3`（160kbps MP3、153.6秒、ループ）。湯婆婆の部屋へ入る際にフェードアウト。

- 第一章の夜の旧市集：7体の霊が市場と石段の周囲を漂う（昼は非表示、暗くなると出現）。

- 第一章の草原：青空・白い積雲・屋根の連なる遠景集落・上り坂の道。

- 全探索シーンの千尋の見かけの大きさを統一（FOV 42°・カメラ距離 4.6m）。カットシーンのみ演出で可変。

- 旧市集の入口側：市場門・両側店舗・石畳・奥の三棟の店構え・樹木を追加し、振り返っても空白の背景が出ないようにした。

- 第一章の冒頭、振り返った背後の風景：曲がりくねった山道・木柵・松・低い山並みを追加。

- 千尋の父：`public/models/dad.glb`（Idle / Walk / Sit、1024px PBR、約 561KB）。田野は Walk、市集の食卓では Sit を使用。

- 千尋の母：`public/models/mom.glb`（Idle / Walk / Sit、簡易人形リグ＋手動ウェイト、1024px PBR、約 429KB）。田野は Walk、市集の食卓では Sit を使用。

- 旧市集の確認用ショートカット：`?scene=town`（タイトルを飛ばして市集から開始）。

- 旧市集の導入：千尋と両親が向かい合って会話 → 両親が屋台へ歩いて行き、椅子に座る。`?scene=town` で直接確認可能。

- 夜の霊：黒い布＋カメラ向きの白い目2つ。父母の市場導入は入口から始まり、屋台へ歩いてから着席する。

- ボイラー室：棘付きのスス精灵が炭を運んで炉へ投げ入れる。運搬完了後にリンが奥の扉から入り、嫌がりながらも湯婆婆の元へ案内する。

- スス精灵は炉前で停止して投げるモーションを入れ、リンは左側の通路を回って釜爺の前を避ける。

- 第二章はボイラー室から直接開始。壁際でもカメラが壁を抜けず、マウス視点を維持。運搬後にリンへ近づいてEで追従タスク開始、リンが扉まで先導する。

- A/D は左右歩行（カメラは回らない）。スス精灵の運ぶ石炭は黒。リンの登場は後ろ扉に水平カメラを合わせてから、扉内から出て釜爺の左を回る。

- 第一章ラストの橋：千尋が橋下の印へ向かうと白龍が現れ、自分と湯屋の説明、両親を救う約束、釜爺への仕事の頼み方を話す。

- 第一章は市場の石段上で白龍と出会って終了。第二章は白龍が橋のたもとで待ち、息を止めて橋を渡る場面から始まり、そのままボイラー室へ進む。

- 第一章の豚は、服を着て腰掛けた姿勢。耳・鼻・目・頬・前脚・後脚・蹄・尻尾・椅子までモデリングし、両親の食卓に座っている。

- 第一章ボイス：千尋（Nanami +24Hz）、白龍（Keita +12Hz）、父（Keita -9Hz）、母（Nanami -4Hz）。`scripts/generate_chapter1_voice.py` で再生成。第一章のみ再生。

- 草原の家並みを草地の奥（z=82〜100）へ移動し、手前の道中には出ないようにした。

- 草原の中ほど（z=24）に小川が横切り、水面・土手・葦・飛び石を配置。渡水中は移動速度が落ち、水音と水しぶきが出る。

- 小川は地形を掘り込んだ河床に水面を置き、深度バッファも有効。石像の前後で正しく遮蔽される。水面は時間で流れるシェーダー、近づくと環境水音が聞こえる。

- 小川の水路は草を完全に除去し、水面を河床内まで下げた。石像の遮蔽、流れる水面シェーダー、距離減衰する環境水音を実装。

- 首页に DEBUG「シーン预览 / 场景预览」を追加。各章の主要シーンへ飛び、その地点から通常の剧情を再生する。角色语音暂时关闭。
