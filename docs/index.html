01 / PROLOGUE

地图之外，
风穿过古门。

十岁的千寻与父母误入一条地图上不存在的土路。旧门楼后是空无一人的市集、摆满食物的摊位，以及一座在暮色中亮起灯笼的汤屋。

父母变成了猪。名字即将被夺走。她必须找到锅炉爷爷，找到工作，也找到回去的路。

04 / CHIHIRO MODEL

把千寻
做成可动的。

独立的程序化角色模型：棕色侧马尾、绿白条纹上衣、橙色短裤、白袜与黄褐色鞋。面部使用参考图贴图，身体由可摆动的关节层级构成。

  • 01待机 / 行走 / 奔跑 / 跳跃
  • 02步频、步幅、摆臂实时调节
  • 03跳跃高度与时长可定制
  • 04所有关节通过 chihiro.joints 暴露
