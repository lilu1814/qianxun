# 文本配置 / Text configuration

编辑 `text.json` 后刷新页面即可生效，不需要重新构建。

## mode

- `both`：日文为主，中文为次级翻译（默认）
- `ja`：只显示日文
- `zh`：中文作为主文本，隐藏日文次级位置

## dialogue

对白与旁白。键名是当前日文文本，**不要改键名**；修改 `ja` 和 `zh` 的值：

```json
"夏の終わり。引っ越しの車は、地図にない土の道に止まった。": {
  "speaker": "",
  "ja": "夏の終わり。引っ越しの車は、地図にない土の道に止まった。",
  "zh": "夏末。搬家车停在一条地图上没有的土路上。",
  "sourceZh": "夏末。搬家车停在一条地图上没有的土路上。"
}
```

- `speaker`：说话人；旁白为空。
- `ja`：日文文本。
- `zh`：中文翻译。
- `sourceZh`：原始中文文本，用于匹配页面里已经存在的中文节点。**除非重置配置，否则不要修改。**

## ui

界面文本。键名同样是原始日文（或英文装饰标签），修改 `ja` / `zh`。
`sourceZh` 用于匹配静态页面中的中文次级文本，请不要改。

## 说明

- 缺少配置项时回退到代码内置文本。
- 修改 `sourceZh` 可能导致已有的中文次级节点无法匹配。
- 对白与旁白的键名来自原始文本；新增台词需要在代码中新增调用，并在本文件补一条同名键。
